# Curso de programacion - Página Web

## ¿Que contiene?

    La página contiene información sobre un curso de programación en Python, su valor, sus caracterísitcas y su metodología.
    
    Además contiene una imágen y video mostrando el curso y un formulario de inscripción

- MAIN
- SECTION
- ARTICLE
- FOOTER
